# Imágenes

Esta carpeta contiene **todas las figuras finales exportadas por los notebooks incluidos en el repositorio**.

- `referencia_local/`: análisis temporal y geoespacial de la implementación Spark local de referencia.
- `depurado_local/`: calidad de datos, comparación antes/después y estabilidad del dataset depurado.
- `databricks/`: figuras regeneradas durante la ejecución cloud en Databricks Serverless.

El `README.md` principal muestra solo una selección para mantener una lectura ágil del portfolio; el resto permanece disponible para auditoría y comparación entre implementaciones.
